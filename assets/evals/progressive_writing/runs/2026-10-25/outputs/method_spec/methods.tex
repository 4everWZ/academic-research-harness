We aggregate an unordered, variable-length set of patch embeddings $\{x_i\}$ into a fixed-length vector $z$. Using a parameter vector $w$ shared across all patches, we score each patch as $s_i=w^\top x_i$, normalize the scores as $\alpha_i=\exp(s_i)/\sum_j\exp(s_j)$, and compute $z=\sum_i\alpha_i x_i$, where the denominator sums over all patches. For example, scores $\log 2$ and $\log 3$ yield weights $0.4$ and $0.6$, which sum to one. The shared scoring function and weighted sum, with no positional features, make $z$ invariant to patch reordering.
